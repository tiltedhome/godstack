# Contributing to this independent cut

Work on `v2gpt` only. Do not change other cuts or their branch sources. Main-branch publication changes must remain additive and preserve every existing path.

Use Node 22. Run `npm ci`, `npm run check`, both builds and `npm run e2e`. Regenerate `LORE.md` with `npm run lore` after canon edits. Keep original prose concise, avoid em dashes, and label fictional leaps separately from science. Pin workflow actions to full commit SHAs. No private email addresses in commits or files.

Respect reduced motion, keyboard controls, muted default audio and responsive layout. Keep the output self-contained. Independent reviews of science, comedy and narrative clarity are useful before substantial canon changes.
